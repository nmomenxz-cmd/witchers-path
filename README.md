# witchers-path
my html js css game project that i spent a lot of hours with the use of a lot of vibecoding to get it to a good level, the game have a lot of systems and code with careful design to not be "AI slop one prompt" game, the main feature of the game is the build menu triggered by pressing B which gives you developer capabilities to make your own world. 

the main keyboard shortcuts are:
I for inventory,
B for build mode which is the heart of the game,
H to call the horse 
Q to cast spells 
R and T for potions

in build menu you can create and script your own npcs and make your own world via terrain manager, you can set behaviour and set animation rig for the in-game npcs or your own .gltf characters if animated and rigged.

the story is where the game is weak at, i didnt add good scipting to make story from build menu, and i dont plan to keep the story coded without flexibility of making it in real-time inside the game since its the atmoshpere
or lets say the idea of game.

also i had to use the witcher as reference when creating the game and plan to make my own style and naming to things but dont have a lot of time unfortunately.
